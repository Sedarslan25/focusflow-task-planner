# FocusFlow Task Planner

A compact React task planner for prioritising daily work. Users can add tasks, categorise them, set a priority, switch between open/completed views, and remove completed work.

**Kısa Türkçe özet:** Günlük işleri kategori ve öncelik ile takip etmeyi sağlayan responsive React görev planlayıcısı.

## Features

- Create tasks with category and priority labels
- Mark tasks as complete and filter by status
- Live total, completed, and in-progress counters
- Responsive interface for desktop and mobile screens

## Tech stack

React 18, Vite 5, and CSS.

## Run locally

```bash
npm install
npm run dev
```

For an optimised build:

```bash
npm run build
```

## Notes

This is a front-end prototype: tasks are kept in browser memory and reset after a refresh. A backend or local-storage adapter can be added as a next step.
